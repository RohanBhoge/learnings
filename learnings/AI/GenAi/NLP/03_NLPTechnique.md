### ## 1. Regex (Regular Expression) 📜
A **regular expression**, or **regex**, is a sequence of characters that specifies a search pattern. It's like a powerful "find and replace" tool used to locate, match, and manage text. Regex is widely used for tasks like data validation (e.g., checking if an email address is in a valid format), web scraping, and parsing text files.

For example, the regex `\b\w{5}\b` would find all words that are exactly five letters long.

### ## 2. ML (Machine Learning) 🤖
**Machine Learning (ML)** is a broad field of artificial intelligence where algorithms are trained on data to learn patterns and make predictions or decisions without being explicitly programmed for the task. Instead of writing hard-coded rules, you feed a model large amounts of data and let it develop its own logic.

ML is divided into several types, including:
* **Supervised Learning:** The model learns from labeled data (e.g., training a spam filter with emails already marked as "spam" or "not spam").
* **Unsupervised Learning:** The model finds hidden patterns in unlabeled data (e.g., grouping customers into different market segments based on their purchasing behavior).
* **Reinforcement Learning:** The model learns by trial and error through a system of rewards and punishments (e.g., training an AI to play a game).

***

### ## 3. DL (Deep Learning) 🧠
**Deep Learning (DL)** is a specialized subfield of machine learning that uses **artificial neural networks** with many layers (hence "deep"). These networks are inspired by the structure of the human brain.



Deep learning excels at finding intricate patterns in large, complex datasets, making it the driving force behind many modern AI advancements like image recognition, natural language processing (e.g., ChatGPT), and self-driving cars. All deep learning is machine learning, but not all machine learning is deep learning.
